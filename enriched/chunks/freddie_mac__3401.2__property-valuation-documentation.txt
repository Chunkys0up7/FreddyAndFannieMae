#### Property valuation documentation

Except for Loan Product Advisor® Mortgages for which the Seller is offered and accepts automated collateral evaluation (ACE), or ACE+ PDR, in accordance with [Section 5602.3](5602.3) or [5602.4](5602.4), the Mortgage file must include all documentation used to determine that the Mortgaged Premises is acceptable, including, but not limited to, an appraisal report and any completion report for appraisals subject to conditions.
