# 3301.2: Seller/ServicerGuide

<!-- chunk: freddie_mac/3301.2 -->

(a)

#### Security Instrument

For Security Instruments that were recorded in paper format, the Mortgage file must contain either:

- The original paper Security Instrument with recordation notation, or
- A paper or Electronic (as defined in [Section 1401.1(b)](/app/guide/section/1401.1#b)) copy of the Security Instrument, with:
  - Recordation notation on the copy of the Security Instrument, or
  - Recordation notation in a separate document maintained with such copy

If the Seller/Servicer maintains an Electronic copy of the Security Instrument (as noted above), it must comply with the requirements set forth in [Section 3302.1(b)(ii)](/app/guide/section/3302.1#b_ii).

If the Security Instrument was electronically recorded, the Seller/Servicer must comply with the requirements set forth in [Sections 1401.3(d)](/app/guide/section/1401.3#d) and [1401.3(e)](/app/guide/section/1401.3#e) related to Electronic Recording of paper Closing Documents and Electronic Recording of Electronic Closing Documents, respectively.

Note: If the Mortgage is secured by a Manufactured Home, see [Sections 5703.4(b)](/app/guide/section/5703.4#b) and [5703.4(f)](/app/guide/section/5703.4#f).
